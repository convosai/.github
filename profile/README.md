## What we build

Convos is a **conversational layer for voter outreach**. Campaigns configure AI agents with approved talking points, curated links, and banned topics. Voters reply in natural language; teams get sentiment, CTA classification, engagement signals, and analytics, all inside a **closed system** trained only on campaign-approved materials.

Built for **campaign managers, political firms, PACs, and advocacy orgs** running peer-to-peer (P2P) texting who need compliant scale, narrative control, and measurable dialogue - not one-way blasts.

| Capability | Description |
| --- | --- |
| **Controlled Dialogue** | AI-assisted two-way texting at scale with guardrails and topic boundaries |
| **Campaign Intelligence** | Real-time alignment, engagement, and persuasion signals |
| **Operational Tooling** | Filtering, profiles, bulk ops, imports/exports, link tracking analytics |
| **Compliance-First** | TCPA / 10DLC-oriented P2P design, opt-out handling, audit trails |
